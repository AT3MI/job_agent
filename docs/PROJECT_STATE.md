## Слой-лингвист — как работает

1. Проверка (1 вызов, единственный в дефолтном пути): модель видит все редактируемые поля,
   возвращает `LinguisticVerdict` — закрытая таксономия `repetition / grammar / tautology / fragment`,
   дословный `quote` (10–200 симв.) и `fixed` (полное исправленное предложение, не абзац).
   Пустой список — валидный ответ.
2. Применение (код): quote ищется посимвольно (с нормализацией тире/пробелов); инварианты:
   числа сохраняются, ссылки/контакты не появляются, длина ≤ ~1.6×, поле из редактируемого набора,
   заголовок `unique_block` заморожен кодом, trigram-guard (правка не дублирует 3+ подряд слов
   из другого предложения того же поля — «запихивание» повтора); замена ровно одного вхождения.
3. Верификация (опционально, `VERIFY_LINGUIST=1`): модель проверяет дифф «было/стало»;
   `ok=false` → правка откатывается (в обратном порядке). В meta фиксируется `verify_mode: off/llm`.
4. Откаты: инварианты применения (отказ правки), per-run (снапшот + `validate_standard`: хуже → откат),
   слой целиком (`SKIP_LINGUIST=1`), уровень кода (git; baseline `db5a39b`).

### Правило зачинов (решение пользователя)

- Зачин (первое предложение абзаца) не переписывается; конфликт «зачин ↔ обычное предложение»
  решается правкой обычного предложения.
- Согласованное исключение: грамматический обрывок ВНУТРИ зачина правится минимально,
  остальной зачин сохраняется посимвольно (иначе «где обследование…» в `vacancy_interest` неисправимо —
  это часть первого предложения).
- Заголовок `unique_block` («По X — отдельно.») заморожен полностью: `ensure_unique_block_format`
  идемпотентен и сам убирает «отдельно — отдельно» до запуска LLM.

## Архитектура и поток данных

```text
data/resume.txt → extract_facts.py → data/allowed_facts.json

job.txt → generate_letter(job_text)
      ↓
STANDARD_PROMPT + generate_standard() → StandardOutput
      ↓
ensure_unique_block_format()          [детерминированный формат заголовка]
      ↓
validate_standard(output, job_text)   [ошибки → retry полей]
      ↓
СЛОЙ-ЛИНГВИСТ (SKIP_LINGUIST=1 отключает), 1 вызов:
      check (LLM) → apply (код: инварианты + trigram-guard)
      [VERIFY_LINGUIST=1: доп. вызов verify → откат плохих правок]
      → ensure_unique_block_format ещё раз → validate_standard
      → хуже, чем было? → откат к снапшоту
      ↓
assemble_letter(output, facts) → готовый текст + metadata (в т.ч. metadata["linguistic"])
```
